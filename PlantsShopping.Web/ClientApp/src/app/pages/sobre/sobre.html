Sobre o PlantsShopping

O PlantsShopping é uma aplicação desenvolvida para facilitar a compra e a doação de plantas, reunindo em um só lugar opções para quem deseja levar mais verde para casa.

O projeto utiliza Angular no front-end e ASP.NET Core com .NET 10 no back-end, disponibilizando uma API REST para o gerenciamento e consulta das plantas.

💻

Front-end

Desenvolvido com Angular 20, proporcionando uma interface moderna, responsiva e intuitiva.

⚙️

Back-end

Construído com ASP.NET Core e .NET 10, utilizando uma API REST para disponibilizar os dados.

🗄️

Banco de dados

Utiliza PostgreSQL integrado ao Entity Framework Core para armazenamento e gerenciamento dos dados.
